Inter-var.woff2 (Inter, variable, weights 400-800, Latin subset; SIL Open Font License) is included.
It is the default English UI font.
PlayfairDisplay-var.woff2 (Playfair Display, variable, weights 400-900, Latin subset; SIL Open Font License) is included.
It is the English headline font.

For the Telugu option, add these self-hosted WOFF2 files (download from Google Fonts, then subset to
Telugu + Latin with pyftsubset or glyphhanger to keep each file small):

  NotoSansTelugu-var.woff2    (Noto Sans Telugu, variable, weights 400-700)
  NotoSerifTelugu-700.woff2   (Noto Serif Telugu, Bold)

Until they are added, Telugu text falls back to the phone's built-in Telugu font.
